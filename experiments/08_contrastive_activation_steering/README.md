# Experiment 08: CASAL-Adapted Contrastive Activation Steering

**Date:** 2026-01-29
**Status:** PENDING (script written, awaiting GPU execution)
**Hypothesis:** Raw residual stream activations (4096-dim) separate AF from HN better than SAE features (16K sparse), because SAE projection loses the intent direction.

## Summary

Adapts the CASAL (Contrastive Activation Steering for Amortized Learning) approach to alignment faking detection. Instead of SAE features, uses raw residual stream activations with contrastive steering vectors at multiple layers.

CASAL adaptation:
- **Step 1 (Probe):** AF vs HN labels already exist
- **Step 2 (Steer):** Contrastive vector `v = mean(AF) - mean(HN)` at 7 layers
- **Classification:** Cosine similarity to `v` + linear probe on 4096-dim activations

Key CASAL insight: extract at **last token position** (aggregates full reasoning context), not max-pool.

## Method

1. **Data:** 25 AF from hard_negatives.json (`alignment_faking`), 25 HN from hard_negatives.json (`hard_negative`). Note: gold_106.json is eval-only and NOT used here.
2. **Extraction:** Raw hidden states at layers [10, 15, 20, 25, 30, 35, 40] with two pooling modes (last-token, max-pool)
3. **Contrastive vector:** Normalized difference-in-means from train set
4. **Metrics per layer:** Cosine classification, projection overlap, linear probe, silhouette score
5. **SAE baseline:** GemmaScope-2 SAE at layer 40 for direct comparison
6. **Validation:** 15/10 train/test split + 5-fold CV

## Possible Outcomes and Interpretation

- **Raw activations also ~91% FPR:** Intent is not linearly encoded in residual stream. Confirms "edges not nodes" hypothesis from Exp 06-07.
- **Raw activations work at specific layers (e.g., 25-30):** Intent emerges mid-network but gets consumed by later layers. SAE at layer 40 looked too late.
- **Raw activations work at layer 40 but SAE fails:** SAE projection specifically loses the intent direction. Supports "intruder dimensions" hypothesis.
- **Last-token beats max-pool:** CASAL's positional insight transfers to AF detection. The final position aggregates reasoning context better than max-pooling.
